# Release v0.4.17

**Delivers a clean root and wrapper `bun audit` (no vulnerabilities found) by landing the three majors v0.4.16 deferred — wrapper `vitest` 4, root `glob` 13, root `ejs` 6 — by upgrade, not by pin. Also carries the post-release checklist path fix.**

## Overview

A dependency-hardening patch release. The headline is shipping the three **major** dependency upgrades that were deferred out of v0.4.16 for separate tracking (wrapper `vitest` 1 → 4; root `glob` 11 → 13; root `ejs` 3 → 6). Because each of those series carries the transitive chains behind the prior audit findings, hardening them together clears the finding counts: root `bun audit` went **11 → 7** (after `glob` 13) → **0** (after `ejs` 6), and the TypeScript wrapper reports **no vulnerabilities found** (down from a chain that included the Vitest UI advisory).

This is a **dependency and build-tooling** patch: no FulmenHQ public API changes, no schema version bumps, and no new standards. It also carries a post-release documentation fix (the release-checklist pull-script smoke-test path correction) that landed on `main` after the v0.4.16 tag.

## Highlights

### Combined `bun audit` — finding counts 11 → 7 → 0

Root and wrapper `bun audit` both report **no vulnerabilities found**. The findings v0.4.16 disclosed and deferred are cleared by these upgrades — no dependency was pinned or overridden to force the result.

- Root finding counts: **11 → 7** (after `glob` 13) → **0** (after `ejs` 6).
- Wrapper: cleared to **0** (after `vitest` 4), including the Vitest UI advisory (GHSA-5xrq-8626-4rwp).

### Wrapper `vitest` 4 — wrapper `bun audit` clear

- `lang/typescript`: `vitest` and `@vitest/coverage-v8` moved from the 1.x series to **4.1.10**; the Bun lockfile refreshed. The wrapper audit chain that included the Vitest UI advisory is cleared.
- **Compiler discovery fix**: the wrapper `tsconfig` `types` allowlist now includes `@types/node`, which vitest 4 requires because it no longer pulls Node typings in transitively; this restores `node:fs`/`node:path`/`Buffer` typings without loosening any compiler option.
- Two obsolete (orphaned) exit-code snapshot entries were removed; retained snapshot values are byte-identical. TypeScript remains on the 5.x series. Headless vitest suite stays green (44 tests / 7 files).

### Root `glob` 13 — glob-path findings cleared

- Root `glob` moved to **13.0.6**; the one call site (`scripts/validate-module-registry.ts`) migrated from the legacy `glob.sync` shim to the canonical `globSync` named export, the forwards-compatible form in glob 13.
- The glob-path `bun audit` findings (minimatch ReDoS / brace-expansion DoS) are cleared; glob 13 resolves to the fixed minimatch 10.2.x / brace-expansion 5 chain.

### Root `ejs` 6 — remaining root findings cleared

- Root `ejs` moved to **6.0.1**. ejs 6 moves the `jake` build tooling out of the runtime dependency tree, which removes the vulnerable `filelist › minimatch` and `brace-expansion` transitive chain.
- The five codegen scripts (exit-codes, fulencode-types, fulhash-types, fulpack-types, role-types) were migrated to ejs 6's ESM shape — the API is exposed on the module's default export — by destructuring `(await import("ejs")).default` before calling `render`. `@types/ejs` 3.1.5 is retained (ejs 6 ships no bundled types); it still typechecks the `render` calls cleanly.
- **Byte-compatible**: regenerated codegen artifacts are identical to before the upgrade (`verify-codegen` green across Go / Python / TypeScript / Rust).

### Docs — release-checklist pull-script path fix

- Post-0.4.16 documentation fix already on `main`: the release-checklist guide's pull-script smoke-test reference was corrected (path and `--dry-run` behavior) so the documented command matches the script as shipped.
