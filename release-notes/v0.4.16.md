# Release v0.4.16

**Adds the cross-language host binary identity standard, hardens the dependency surface (goneat v0.5.16 pin + minor/patch bumps), and aligns markdown formatting under the lifted toolchain.**

## Overview

A standards-and-hygiene patch release. The headline is the new **Host Binary Identity Standard** (`host-identity`): a shared cross-language `version --extended` contract so operators can dump build provenance, triage dirty binaries, and separate "what am I actually running" from "what SDK/SSOT was it built against". In the same cut we refresh the dependency surface — lifting the goneat tooling pin to v0.5.16 and applying in-scope minor/patch bumps across the root and TypeScript wrapper manifests — and align markdown to the goneat v0.5.16 formatter so synced docs stay deterministic.

No fulmenhq public API changes and no schema version bumps; this is a patch release.

## Highlights

### standards: Host Binary Identity Standard (Added)

- New cross-language standard defining the `version --extended` field contract: canonical camelCase JSON + text shapes for version, commit, buildDate, dirty, runtime, and platform.
- **Host identity vs SDK/SSOT pins** separation: pins are extended-only, reported under their own labeled block (`Pins:`/`Crucible:`/`SSOT:`), and **never** surface as the host `Commit:` — the host `Commit:` is the binary's own source commit only.
- **Explicit dirty semantics**: `true`/`false` when determinable (a known-clean tree reports `false`), `unknown`/omitted when the VCS probe fails — never a misleading `false`.
- **Phase A** build-time injection recipes that require **no helper library**: Go Makefile ldflags, Rust `build.rs` + `env!` (RFC3339 build date, `rerun-if-env-changed`), and TypeScript/Python build-time-stamp-primary with a documented, caller-influenceable `FULMEN_HOST_*` env fallback.
- **`FULMEN_HOST_*` injection contract**: CI may inject identity; no runtime `git` probe is forced inside released binaries.
- **Trust boundary**: host identity is informational, not attestation — never consumed for auth/integrity/security decisions.
- **Phase B gate**: prefer future `gofulmen`/`rsfulmen` resolver libraries once they ship; no invented import paths in the meantime.
- Link wiring: Cobra CLI guide and CLI-category README point to the hub; the app-identity guide and module carry one-line runtime-vs-build cross-references. Propagated to all language wrappers via the standard sync pipeline.

### deps: goneat v0.5.16 pin + minor/patch dependency bumps (Changed)

- Makefile `GONEAT_VERSION` lifted `v0.5.13 → v0.5.16`, matching the local toolchain and current train, for consistent format/assess/validate behavior.
- In-scope minor/patch bumps across the root and `lang/typescript` manifests: `js-yaml`, `@biomejs/biome`, and `@types/node`; both Bun lockfiles refreshed and frozen-install verified.
- Go surface unchanged (`gopkg.in/yaml.v3` already current; no `go.mod`/`go.sum` drift).

### tooling: markdown aligned to goneat v0.5.16 (Changed)

- Whitespace-only markdown normalization (blank line after list markers) across root docs/schemas, release notes, and synced wrapper docs, matching the lifted tooling pin. No content change.

## Breaking Changes

**None to public API or schema versions** — this is a patch release; all schemas remain at their current versions and additions are backward-compatible at the contract level.

**Dependency note:** `bun audit` continues to report pre-existing transitive findings via deferred major-track toolchains (`glob`/`ejs` at the root; `vitest`/`vite` in the TypeScript wrapper). None are introduced or worsened by this release, and remediation is deferred to the corresponding major bumps.
