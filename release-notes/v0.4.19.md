# Release v0.4.19

**A documentation patch: helper libraries gain a file-backed JSON Schema instance-validation contract (on-disk catalogs, offline `$ref`, path containment), forge module tables point at that contract, and overview docs mark rsfulmen as an active language foundation at Rust 1.88.**

## Overview

A documentation-only patch release. The headline is the Schema Validation Helper Standard: helpers must validate instances against **caller-supplied on-disk schema trees** as well as embedded Crucible ids. Those catalogs are not vendored into the helper. `$ref` resolution is offline; `file://` and relative refs stay inside the canonical root-schema directory and caller `RefDirs`.

The same cut records that Workhorse and Codex stay REQUIRED to call the language helper for schema validation, Microtool stays OPTIONAL (helper only when used), and the language-foundation table matches `config/taxonomy/languages.yaml`: **rsfulmen is Active**, published minimum **Rust 1.88**. `csfulmen` stays planned.

This is a **documentation** patch: no FulmenHQ public API changes, no schema version bumps, and no new features in the language libraries themselves. Implementations land in the helper repos after this tag.

## Why This Matters

**For helper-library implementers (Go, TypeScript, Python, Rust):** there is one contract for instance checks against schemas that live beside the binary. Do not wrap jsonschema/AJV in each application, and do not subprocess goneat at runtime for those checks. `http(s)` `$id` values are catalog keys, not network fetches.

**For forge and application authors:** Workhorse and Codex must use the helper for both Fulmen embeds and application schema trees. Microtools that validate structured JSON/YAML use the same APIs. Do not supply an open-filesystem resolver that bypasses catalog-root containment.

**For readers of the ecosystem map:** rsfulmen is a current language foundation (Roan is the Rust workhorse breed), not a planned item. The published Rust minimum is 1.88, matching the rsfulmen crate.

## Highlights

### File-backed catalog instance validation

Helpers validate instances against on-disk schema families the helper does not embed. Offline `$ref`. Same diagnostic taxonomy as embed-id APIs. Existing `ValidateFile(id, path)` is not overloaded.

### Containment

Allowed roots are the canonical directory of the root schema file and each `RefDirs` entry. Traversal, symlink escape, unsupported URI schemes, and non-local `file:` hosts fail at compile time, not as instance issues.

### Forge module tables

Workhorse / Codex: REQUIRED via the helper. Microtool: OPTIONAL; when used, helper only.

### rsfulmen Active

Overview docs and `languages.yaml` agree: rsfulmen is Active; published minimum Rust 1.88.
